# 截图工坊 · Screenshot Studio

把任意应用截图做成 **App Store 首图风格** 的高清展示图：渐变底色 + 机身框 + 局部放大框 + 大标题，
支持拖拽排版、多套模板、一键导出 1290×2796 的高清 PNG。

纯前端、零依赖、不联网、不上传 —— 图片只留在你自己的浏览器里。

---

## 快速开始

**方式一（推荐）**：起一个本地服务，剪贴板按钮等功能才可用

```bash
cd /Users/arcade/WorkBuddy/截图网站
python3 -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

**方式二**：直接双击 `index.html`。绝大多数功能可用，只是「从剪贴板」按钮会因浏览器安全策略失效（⌘V 粘贴仍可用）。

## 四步做完一张图

1. **导入截图** —— 拖进窗口 / ⌘V 粘贴 / 点「选择图片」。首图导入后会自动生成一个放大框。
2. **框选要放大的细节** —— 左侧「放大镜」面板里拖框（或点「精细框选」开大图操作），也可直接在画布上拖动 / 拖角缩放放大框。
3. **写文案** —— 「文字」面板改标题、副标题、颜色、字体字重；用**「文案位置」**把整段文案切到画布上方或下方，设备会自动让位到另一侧；「标注」面板加气泡文字和小箭头。
4. **调外观 → 选模板 → 导出** —— 「设备」面板调手机边框、圆角、投影；「模板」面板切换 8 套排版；「导出」面板点 **「导出 6.7" / 6.5"」** 一键出图，也可打包全部模板。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `⌘V` | 粘贴剪贴板里的截图（有主图时自动成为副图） |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⌘S` | 导出当前模板 |
| `Delete` | 删除选中的放大框 / 贴纸 |
| `↑↓←→`（+`Shift` 加速） | 微调选中的放大框 / 贴纸位置 |
| `Shift` + 拖角 | 临时忽略比例锁，自由变形 |
| `Esc` | 关闭弹窗 |

## 导出规格建议

| 用途 | 规格 | 画布比例 |
| --- | --- | --- |
| App Store iPhone 6.7" | 1290×2796 | 430×932 pt |
| App Store iPhone 6.5" | 1242×2688 | 414×896 pt |
| App Store iPhone 6.9" | 1320×2868 | 440×956 pt |
| App Store iPad 12.9" | 2048×2732 | 1024×1366 pt |

> 导出面板会实时显示最终像素尺寸；当画布比例和 App Store 规格不一致时，会给出「切换画布到该比例」的提示按钮。

源截图建议宽度 ≥ 1170px（面板里会提示），否则放大区域的清晰度会打折 —— 放大的本质是把原图像素放得更大。

## 技术说明

- **一套渲染函数走天下**：预览和导出都走 `WB.renderScene(ctx, state, scale)`，导出时只是把 `scale` 换成目标像素比，
  所有文字、描边、圆角都在目标分辨率下重新光栅化 —— 所以 3 倍导出是真正的高清，而不是把小图放大。
- **设计坐标系**：所有尺寸以 pt 记录（App Store 6.7" = 430×932 pt），导出比例 = 目标像素宽 / 430。
  切换画布规格时会按比例缩放全部 pt 尺寸，排版不跑偏。
- **放大框取值**：源区域用归一化坐标（0~1）记录，因此换画布尺寸不会错位；「锁定比例」保证放大不变形。
- **文案位置翻转**：每套模板记录自己的文案锚点（上/下/居中）。切换「朝上/朝下」时把文案块整体平移到对侧，
  再把设备按**包围盒**搬到剩余的空白带，并垂直居中 —— 所以双机这类错落构图不会被拆散；当空白带放不下时
  整体等比收缩，保持「设备完整可见」的既有规则。蒙层（满屏模板的渐隐底）方向同步跟随。
- **零依赖**：没有构建步骤、没有 npm 包、没有网络请求（字体走 Google Fonts，离线时自动回退系统字体）。

## 已验证

用 Chrome 跑过端到端自动化测试：粘贴导入、画布拖拽 / 拖角缩放、侧栏框选、标注气泡与引线拖拽、
撤销重做（含状态回滚）、贴纸、透明背景、JPEG 导出、8 套模板批量导出 ZIP（`unzip -t` CRC 校验通过）、
画布规格切换（字母/圆角/投影按比例缩放）—— 全程无控制台报错。

**「文案位置」专项**：扫描 3 种源图比例 × 3 种画布 × 8 套模板 × 2 个方向共 320 种组合，其中
160 个真正发生重排的组合全部通过 —— 设备完整落在画布内、与文案零重叠、且确实位于文案的另一侧；
蒙层方向跟随文案翻转。

**快捷导出**：实际产出像素经 PNG 文件头校验为 1290×2796 与 1242×2688（而非按比例算出的近似值），
且导出前后编辑画布尺寸不变。

`examples/` 里 8 张图就是这套流程产出的（1290×2796，源截图 1170×2532）。
